# 展示视频平实且尽早展示主体

展示视频尽早呈现真实产品或演示对象。形式要能解释内容，字幕平实、少而有用，留出只看画面的时间。

**Why:** 没有内容依据的形式和抒情会分散注意力；逐句报数也会挤占画面本身的表达空间。

**How to apply:**

- 每种画面手法都对应需要解释的关系或变化，不只因为参考片好看就套用。
- 能放进图中的数字做成标签；不设无来由的叙述角色，不写献词式自我抒情。
- 镜头起止逐帧检查提示框、字卡和转场，避开缺字、黑块等短暂异常。
- 配音按实测语速和画面时长安排，留出停顿，不靠加速硬塞文字。
- 讲解段用完整配乐；实录声音用于对应的真实演示。旁白下按段压低配乐，短停顿不立即抬回，避免反复抽吸。
- 交付前回听并转写旁白，逐张检查字卡，删除制作备注、内部建议和写给创作者本人的文字。

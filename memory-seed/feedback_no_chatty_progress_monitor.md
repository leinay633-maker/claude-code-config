# 后台通知只保留有效信息

长后台任务不额外开按固定时间或百分比推送的通知循环。保留完成、错误和终止信号；需要进展时读取日志。

**Why:** 没有新信息的通知会打断工作，还可能触发重复回合和提示。

**How to apply:** 使用工具已有的完成通知；确需监控时过滤重复事件。必要的状态更新仍交代新发现、阻塞和下一步。任务完成后接着做校验与交付，不只发一条“跑完了”。

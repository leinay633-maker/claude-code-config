# 要复制或照做的内容直接展示

需要复制的文本和照着执行的清单，在回复里给出完整内容，不只提供文件链接。

**Why:** 往返查找文件会打断操作，也容易漏复制或复制错版本。

**How to apply:**

- 文本单独成段，保持可直接选中；不要用引用块承载要粘贴的正文。
- 清单和表格保留操作所需的全部值，不因合并相同项而漏信息。
- 需要粘到上传框或其他程序的路径，单独给纯文本路径；任务附件仍按全局交付规则列真实文件链接。
- 需要留档时另存文件，回复中仍给出当次要用的正文。

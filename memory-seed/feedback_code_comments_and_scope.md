# 注释保留原因，测试限定范围

代码注释保留必要的原因、协议约束和不明显的边界条件，不写排障流水、当次对照结果或重复控制流的说明。

**Why:** 历史复盘容易过时，也会遮住真正的约束；顺手优化会让一次查询或验证变成行为变更。

**How to apply:** 编辑前限定请求范围。清理注释时保留“为什么必须这样”的短说明。只要求测试或查询时，先完成验证和汇报；发现业务问题单独指出，不把修复混入验证改动。

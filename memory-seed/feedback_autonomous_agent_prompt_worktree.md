# 自主任务使用明确仓库和独立工作区

自动执行任务的说明应指定目标仓库和允许修改的范围。需要独立开发时使用单独的 Git worktree，不让执行者从启动目录自行挑选仓库。

**Why:** 多个会话共享同一工作目录时，切分支、暂存和还原会改变其他任务看到的文件状态。

**How to apply:**

- 开始前核对目标目录确实属于指定仓库，并检查当前分支和已有改动；不符合预期就停下报告。
- 在约定的工作区根目录创建独立 worktree，例如 `git worktree add -b <任务分支> <独立目录>`。
- 原工作目录不做未授权的切分支、`stash`、`reset` 或提交。
- 任务说明写清允许的产物、验证方式和提交边界；只读任务只出报告。
- 同步或交付前重新核对实际分支，不凭上次会话的分支名称判断。

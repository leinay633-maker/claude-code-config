# PowerShell 解析与命名易错点

自定义函数用清楚的 Verb-Noun 名称。PowerShell 的别名可以遮住同名函数；执行结果异常时先用 `Get-Command <名称> -All` 核对实际调用对象。

- 数组元素中有字符串拼接时，给该元素加括号，例如 `@('# 标题', ('# 编号：' + ($ids -join ',')))`。
- 变量名不区分大小写，不要用 `$e` 和 `$E` 表示不同对象，改用不同的完整单词。
- `-match` 默认不区分大小写；需要按大小写区分日志关键字时用 `-cmatch`。
- 中文弯引号也可能参与字符串解析。含这类文本时，用 ASCII 单引号包住内容，或把展示用引号换成「」。
- 复制、移动和删除时写全 cmdlet 名称，对输入路径用 `-LiteralPath`，复制和移动明确指定 `-Destination`。
- 文件操作可能产生非终止错误。需要失败即停的步骤用 `-ErrorAction Stop`，先核对源路径，执行后检查仓库差异或目标文件。

**Why:** 解析与命名冲突可能没有明显报错，却让命令操作错误对象。

**How to apply:** 先用小输入确认命令解析、数组形状和匹配条件，再执行文件变更。不要把后续步骤成功当作前一步成功的证据。

# 片名表达主题与问题

起片名先确定视频回答的问题或讨论的主题，再写成问句或主题句；需要补充对象时加一行副标题。

**Why:** 只有干名词、操作守则或指标变化，往往不能说明观众为什么要看。

**How to apply:**

- 长度服务理解，不为追求短而只留下抽象名词。
- 避免祈使句、训诫口吻、单纯报数和照搬参考频道的句式。
- 标题与最终结果一致，不夸大，也不把过程中的某次弯路误写成整部片的结论。
- 需要审美确认时，给少量能准确表达主题的候选，并说明各自强调什么。

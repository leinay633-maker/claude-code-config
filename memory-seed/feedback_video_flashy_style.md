# 画面变化服从统一风格

需要视觉表现力的视频，优先让每段的主体、构图、运动和空间层次有变化，同时维持统一的视觉语法。

**Why:** 重复构图容易乏味，堆叠粒子和辉光又会削弱主体；变化要能帮助观众理解内容。

**How to apply:**

- 用前景、中景和背景建立层次，高潮效果按题材选择，避免每段都用同一种镜头运动。
- 全片配色、字体、线宽和发光规则固定；多变主要来自画法和构图。
- HyperFrames 工程按当前组件目录寻找适合的能力，再补缺失实现；程序生成的 MV 按 `make-video/mv.md`。
- 科普讲解片按 `make-video/explainer.md` 的常驻框架与原地变化；无旁白知识短片按 `make-video/vibe.md`，不强行共用一套特效。
- 视觉表现力不要求文案抒情。

# 视频修改按影响范围处理

视频修改先确认影响画面、音轨还是时间线。能局部处理的改动按影响范围处理，小问题集中一批再出下一版。

**Why:** 整片渲染成本高，重复编码不一定提升可感知质量；时间线不变时音频修改可以独立交付。

**How to apply:**

- 只改旁白且画面不变时，把新音频补静音或裁到原段长度，重新混音后复制原视频流、替换音轨；常用映射为 `-map 0:v -map 1:a -c:v copy`。
- 若音频时长或动作对齐改变，重新评估时间线，不能机械套用只换音轨。
- 渲染前完成旁白转写、发音核对和关键帧检查。问题集中修订，每个确认版本只做一次正式渲染。
- 自动转写的同音字偏差先回听，修正确定念错且影响理解的内容。

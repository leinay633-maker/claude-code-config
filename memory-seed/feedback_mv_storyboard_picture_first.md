# MV 分镜先确定画面主体

写 MV 分镜时，先说明镜头里有什么物件、场景或图，再决定歌词怎么放、怎么动。

**Why:** 只写文字效果和界面状态的分镜，容易变成整段大字；增加动画也补不出具体画面。

**How to apply:**

- 每个对句或视觉段落先定一个叫得出名字的主体；歌词通常做角落字幕，必要的大字与主体发生关系。
- 终端、列表、面板和进度条作为点缀，避免连续多镜都由界面文字充当主体。
- 具体物件选能清楚识别的建模、线描或网点画法；除非主题需要，不用低分辨率方块代替形体。
- 分镜自查时遮住全部文字，确认每镜仍有可看的主体和动作。

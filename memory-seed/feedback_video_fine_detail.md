# 细节来自结构与可读层次

先确定细节从哪里来，再加效果。纹理型画面可用排线、线描、网点和纸纹；信息图以真实数量、线条和标注构成细节。

**Why:** 大面积模糊和散景容易抹掉结构；同一种纹理铺满也会挤压主体和留白。

**How to apply:**

- 纹理型画面在 1080p 下可从约 1–1.5 px 的锐利线条试起；按目标分辨率和压缩结果调整。
- 组织大标题、主体、注释或纹理三种尺度，保留负空间，不把小字当成必须阅读的正文。
- 模糊主要服务景深，发光只给约定的重点，正文保持清楚。
- 用原尺寸裁图检查边缘和纹理。若工程提供细节统计，结合局部图判断，不套跨风格统一的百分比。
- 仪表盘讲解和无旁白知识短片不强制加排线、颗粒；它们按对应风格说明处理。

# 公开视频从头组织内容

准备公开的视频，从选题问题、资料和独立提纲开始。参考作品只用于理解一般制作方法，不直接复述其独有的结构、经历、观点和措辞。

**Why:** 换掉署名或声音不能把照搬内容变成原创；虚构经历还会造成事实错误。

**How to apply:**

- 从可核对的资料重新组织论证，旁白和字幕从头写，不沿某一参考片的段落顺序复述。
- 不把参考作者的个人经历改成第一人称，也不为讲述者编造经历。
- 来源信息按实际使用和发布要求保留，不把删掉来源当作原创处理步骤。
- 稿件、图像、配乐和片名分别核对，避免连同参考作品的专属标识一起沿用。

# Windows 后台任务的进程与资源

## 先确定任务应活多久

工具可能在停止外层任务时结束整个进程树。`Start-Process -WindowStyle Hidden` 只处理窗口显示，不保证任务在停止会话后继续运行。

确实需要独立运行且已获授权时，可评估 `Win32_Process.Create` 这类独立启动方式。是否能跨越终端关闭或外层任务停止，必须分别实测，不只按父进程推断。

- 独立启动时明确解释器位置、工作目录、日志和退出结果的读取方式。
- 不假定独立进程继承当前工具调用的临时环境变量；所需变量显式传入。
- 记录实际 PID 与任务归属，重启前确认旧实例已结束，避免两份任务同时改同一批文件。

## 内存与退出状态

- 长任务前检查可用内存，预算依据实际工作进程及其后代的峰值，不沿用固定阈值。
- 任务被资源保护停止时，先查通知与日志、保存可恢复状态，再决定重试。
- 关闭窗口可能只是缩到托盘。释放资源后检查进程和内存，不把窗口消失当成退出成功。
- 不通过独立启动绕过资源保护；只处理已授权的任务进程。

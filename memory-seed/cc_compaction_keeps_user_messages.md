# 上下文压缩后恢复证据

上下文压缩后的保留内容取决于工具版本和摘要策略。不要承诺全部指令或固定数量的文件会被保留，也不要仅凭摘要结构推断恢复完整。

- 长任务的关键命令、报错原文、权威文件位置和未完成动作写入可继续使用的任务记录。
- 恢复时先区分摘要里的结论和可重新读取的证据。涉及具体数值、错误或文件内容时，回到当前来源核对。
- 摘要没有提到某条约束，不等于约束已取消；以当前明确指令和可读取的规则为准。
- 只有路径、没有正文时不要声称仍掌握文件细节。工具明确返回文件未变时，可按已有读取记录说明复用依据。

# 澄清指代并减少重复追问

在全局沟通规则之外，注意短指代和纠正信号：“这个”“那份”存在多个候选时，先用一句话复述对象再继续。

**Why:** 技术方案正确也可能落在错误对象上；逐次发现本可提前看出的分歧，会增加沟通成本。

**How to apply:**

- 收到纠正时，先回头检查对象、范围和前提，不只按字面追加解释。
- 澄清前读完已有材料，先消解可自行判断的小分歧，留下当前必须确认的一个问题。
- 新材料中的细小差异按最贴近原意的方式处理，必要时在草稿中标明，不把可审阅的小改动拆成连续追问。

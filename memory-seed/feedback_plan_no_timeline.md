# 计划按依赖和完成标准组织

任务计划按依赖顺序列要做的事与完成标准；没有给定期限时，不凭空分配周数或完成日期。

**Why:** 没有工作量依据的日程会变成虚假的限制，掩盖真正的依赖和等待条件。

**How to apply:** 每步说明输入、产出和结束条件。确实需要估时，再分块说明工作量、外部等待和不确定性，不先报一个笼统周期。给协作者的任务说明也不附加无依据的期限。
